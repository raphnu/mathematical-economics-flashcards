# Mathematical Economics · Part I

Leitner flashcards: 68 cards across 9 topics. Exam: 2026-12-15.

**Open on iPhone:** Safari → https://raphnu.github.io/mathematical-economics-flashcards/ → Share → Add to Home Screen. Always study from the
home-screen icon; it works offline and keeps its own progress.

- Boxes: Box 1 every 1 day, Box 2 every 2 days, Box 3 every 4 days, Box 4 every 7 days, Box 5 every 12 days. Right = up one box. Wrong = back one box, back tomorrow, and repeated once at the end of the session.
- Open questions: reveal, then rate yourself. MCQs are graded automatically, options shuffled each time.
- Cards live in `deck.json` (the source) and `deck.js` (generated from it). Edit `deck.json` and rebuild;
  keep each card's `id` unchanged so its progress is kept.
